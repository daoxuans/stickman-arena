# 视觉与交互设计基线（当前实现）

这是从 [页面](../public/index.html)、[样式](../public/styles.css) 和 [画面绘制](../public/render.js) 归纳的**现行基线**，用于让下一位开发者/AI 延续已有风格；它不是用户签字的品牌规范，也不宣称通过真实设备视觉或无障碍验收。玩法、字段与状态以 [PRD](../outputs/PRD-火柴人竞技场-20261004.md) 为准。

## 体验与视觉层级

- 品牌用“线斗 / STICK ARENA”：倾斜三笔的 CSS 图形、中文主字标和紧凑英文辅助标。不要无缘由换成图片商标或另一套命名。
- 战斗画面优先占据首屏；舞台外是深墨绿框架，右侧路线/房间操作放在浅矿物纸色面板。单人以 960 宽视口窥见 1920 宽的横向关卡世界，联机以同宽视口窥见 2880 宽的绘制战场；两种模式都跟随本方人物，联机镜头各端独立。当前任务一眼先看对战，再看进度或房间操作。
- 暖橙为主操作、当前关和 P1 提示；珊瑚红区分对手及部分警示，机关仍按各主题使用自己的色彩；四主题绘制场景分别采用森林蓝绿、城市紫灰、海洋青蓝、陆地赭石。场景调色不等于整站切换四套 UI 主题。
- 角色保持“大头、细身、细肢”的火柴人比例；可操控的人类角色（单人主角与联机 P1/P2）以用户提供的侠客图为造型参考：低檐、不规则破边的深色编织蓑帽，默认暗色面部以亮眼表达情绪，颈部围巾和流动的披风。P1 以赤红披风为识别点，P2 用对比明显的冷色；这不是对原图的逐像素复制，原图也不作为公开游戏素材。帽檐不能遮没默认脸情绪或自选头像与 KO 番茄落点，披风不能吞没细肢与攻击朝向；画面中的刀只作气质参考，拳、踢、投矛等招式不变。敌人和 Boss 不因此换装。普通头半径约 22 个逻辑像素、肢体核心描边多为 4.2–4.8，Boss 整体视觉约放大 1.28 倍并加宽肩线；服饰只是轮廓/动效，不改变人物命中范围。

## 布局与组件语义

| 区域/组件 | 当前规则 | 保持一致时的关注点 |
|---|---|---|
| 总体 | 内容最大宽度 1800px；页头放品牌、居中的双模式页签和会话/音效；主区左舞台自适应、右面板约 296–342px。 | 两模式共用舞台外壳；右面板、舞台画面、标题、HUD 与覆盖层须按模式同步更新，且舞台保持主视觉地位。 |
| 舞台 | Canvas 逻辑视口 960×540、CSS 维持 16:9；单人世界 1920×540、联机世界 2880×540，均水平跟随本方/边界停止；顶部叠放 P1/P2 血条和波次/时间，状态覆盖层覆盖画面。 | 镜头只移动世界层，HUD/按钮/覆盖层保持屏幕固定；联机离屏对手用方向/距离提示，不让双方在大场地互相失联。HUD 左右身份、波次与时间含义不能混。 |
| 路线/房间面板 | 浅纸色、高对比深字；路线 7 列数字节点，当前/存档/Boss/已通关/锁定有不同标记。练习关另有色框和 `aria-pressed`，右侧出现“退出重打 · 返回主线”。 | 已通关节点可作为临时重打入口，未通关/锁定不可跳关；练习期间主线存档/进度/失败次数仍以“主线”标示，切换另一已通关节点仍只属练习，不把结果冒充正式过关。 |
| 头像设置 | 页头“我的头像”常驻入口（窄屏收起文字但保留按钮），正式准备覆盖层另有“设置头像”；深底对话框含圆形预览、上传、网页相机、权限失败后的系统相机/相册回退、恢复默认和关闭。 | 单人战斗中打开对话框暂停；关闭后按正式/练习分别显示“继续主线”或“继续重打”，再由玩家恢复。联机倒数/正式对战暂禁改，本地失败提示不阻断开战。相机轨道在关闭/失焦时停止，状态文字与键盘焦点须保持可用。 |
| 装备 HUD 与背包 | 单人舞台下方显示已选装备名称、阶级/伤害或剩余冷却，并有“背包 n/9”入口；B 键也可开关背包。深色背包对话框列出已获得装备的名称、阶级、伤害、射程、约合秒数的出招间隔及“已装备/装备”状态。 | 战斗打开背包先暂停，清除长按输入；关闭后恢复先前战斗，未开始或结果层不凭对话框启动战斗。首次拾得自动装备，后续不擅自切换；选装后 HUD/触屏装备技同步。练习所得及选择只在临时现场，退出还原主线背包；联机隐藏这一组控件。键盘焦点、关闭按钮与 Escape 取消需可用。 |
| 按钮 | 暖橙主按钮、深色次按钮、描边/安静按钮；禁用有低不透明度；模式选中有底部暖橙强调线。闯关/联机投矛都显示剩余 0–5 发：未瞄准时“投矛”，瞄准时“发射”，增显“抬高”“压低”“取消”；触屏调角旁显示仰角。联机也显示 L 光波的命中进度/可用状态；仅单人触屏有装备技，联机隐藏背包和装备技。 | 联机的投矛余量每局每人独立，光波按本人真实命中 3 次充能；不能把闯关的按 KO/全波伤害暗示为联机规则。瞄准拖动松手不发射；装备技不是投矛或光波。 |
| 细节 | 直线、画框角线、斜切笔画、存档菱形为几何语言；地图格仅轻微圆角。 | 不要误读为“全站禁用圆形”：人物头、光波和装饰环本来就是圆形。 |

响应式现状：宽度 ≤1100px 主区上下堆叠；≤760px 页头折行、键盘提示隐藏并显示触控按键；≤540px HUD 隐藏生命数字但保留血条；≤360px 进一步压缩标题与按钮；粗指针设备即使宽度 >760px 也显示触控。页面声明最小宽度 320px，不代表更窄设备经过验收。

## 动作与反馈的视觉语法

| 动作/事件 | 当前表现 |
|---|---|
| 拳击 | 有效帧在拳头附近出现弧形拳风；没有光箭、远程投射物。三段出拳节奏不同。 |
| 连段/胜负表情 | 无有效本地头像时，连续挥拳表现努力发力、胜利开心、失败与 KO 伤心；表情绘于夸张大头，不能代替血量、KO 番茄和文字结果，也不能在状态变化后残留相反情绪。有有效本地头像时不再往本人的照片上叠绘默认眉眼口/表情。 |
| 本地自选头像 | 开战前可选本机照片或拍照，文件最多 8 MB、边长≤8192px，缩为 192×192 后裁入本人圆形头部；未选择/清除/刷新用默认脸及其动态表情，处理失败保留原有效头像/默认脸。头像生效时不在本人脸上叠绘系统默认眉、眼、嘴、胜负或连段表情；头部轮廓、帽檐、围巾、披风、KO 番茄在照片外保持可辨，血量与结果文字继续承载状态反馈；不让照片方框越出头部或盖住判定线索。联机本端只给本人 P1/P2 绘本机照片，对手仍见默认脸及其表情；头像不参与生命、命中或跨端同步。 |
| 已通关重打 | 已通关节点是可操作的练习入口，正式当前关仍保持进度高亮，另用绿框标出练习所选关；未通关/锁定节点不得用同一可点击暗示。练习开始层写“开始重打/返回主线”，成功/失败层写“再打这一关/返回主线”，右侧始终可退出，亦可点另一已通关节点换练习关；退出回到原正式现场并暂停待“继续主线”，不把练习胜利写成“进入下一关”或让玩家误以为会覆盖存档。 |
| Boss 掉落与拾取 | 九场 Boss 各固定掉一件颜色/符号/阶级可辨的装备。掉落徽章在 Boss 倒地的世界脚点上方，随移动平台上的尸体移动；尸体消失后往可拾地面落，镜头跟随不能造成漂移。约 14 有效帧后主角靠近自动拾取，局部短环与文字提示说明“已收入背包”，若已有同件则提示不重复叠加。 | 徽章与地面陷阱、坠物预警、小石或投矛应明显不同，不能盖住危险边界。末敌收尾可走近拾取，但也明确提示未拾掉落在过关时自动收纳；拾取动画与背包数量不应暗示未过关就永久保存。减少动态效果下保留静态徽章/文字/短环，联机不绘掉落。 |
| 装备出招与层次 | 1–5 阶九件的基础伤害按 Boss 关位从 15 到 24，射程 88–126、冷却 44–60 有效帧；背包中显示精确数值，让玩家知道收益和出招间隔。风格为 `sweep`（持械横扫）、`pierce`（前向突刺）、`pulse`（近身脉冲），由角色动作与装备色区分；真命中有局部环/短音，空挥只听轻微兵器起势，不冒充命中。 | 本版都是朝向前方、高度重叠才会命中的独立单目标招式，不是全屏冲击、远程箭头或新的光波；每次最多伤一名敌人、长按不连发。Boss 护体、目标闪避/无敌仍有效。装备出招中不叠拳/踢/投矛蓄势，收尾和 PvP 都不用。别让高阶色彩或光效遮住蓑帽/头像、番茄、陷阱或血条。 |
| 蓑帽、围巾与侠客披风 | 单人玩家及联机双方都戴深墨色、低檐破边的编织斗笠式蓑帽；默认暗色大头以亮眼和眉眼形状表达开心、伤心、发力，自选照片生效时只展示照片本身、不叠默认表情。P1 赤红围巾/披风与 P2 冷色围巾/披风在四主题和照片背景上区分人物。披风尾端随水平移动向反方向扬起，起跳/落下时跟随身体姿态变化，减速时逐渐回垂；不盖住拳风、踢击、投矛瞄准弧线、默认表情或自选照片及 KO 番茄。减少动态效果时保留静态披垂轮廓，不随速度/时间持续飘动，但仍随朝向/KO 姿态更新。服饰不参与命中、碰撞、伤害或存档。敌人/Boss 保持原造型；不新增刀类武器。 |
| 地面踢/跳踢 | 脚端能量；空中跳踢在有效帧出现碎光、扩散环与短促震屏，空挥仍有完整动作。 |
| 玩家投矛 | 与贴拳拳风明确区分：闯关与联机均先按 I/“投矛”进入瞄准，舞台显示由当前发射点、朝向和 8°–72° 仰角推算的理论弧线及预计落点；闯关初始角参考前方最近敌人，联机可参考前方对手，无合适目标时为 42°，绝不显示锁敌/必中效果。W 抬角、↓/S 压角，触屏“抬高/压低”可按住微调，舞台竖向拖动松手不发射；↑ 与空格用于跳跃，↑ 不再抬角，瞄准中按 ↑ 先取消未确认瞄准再尝试跳跃，左右仍能走位/转向。再次按 I/“发射”锁朝向/角度，约 20 有效帧蓄势后投出；惯性、动态平台及对手移动可令真实落点不同。Esc/“取消”或拳、踢、跳、闪、受击/KO 等只退出未确认瞄准；已确认蓄势在单人暂停/切模式后保留、返回闯关继续有效帧，联机失焦由服务端继续本局，联机切模式离房后不保留该局蓄势；受击或成功光波可打断。屏幕显示闯关本关或联机本局的剩余 0–5 发；仅实际投出扣 1，单人跨波共享、换关/回档重置，联机重赛重置。按住 I 不连发；联机对方的弧线/飞矛及平台遮挡按服务状态绘制，不用本端画面自行判定。 |
| 单人敌人投矛 | 中后期具备资格的敌人沿用自动锁定玩家当时位置的可辨前摇/预告路线，出手后飞行不追踪；敌我双方都可走位、借平台遮挡或闪避。联机没有 AI，P1/P2 各按自己的 I 与仰角操作。 |
| 联机长场地与光波/机关 | 四主题绘制背景在 2880 宽世界横向衔接，不引用单人照片；中段对称出生，镜头随本端人物。离屏对手有方向提示；旋转木条和水平浮台的绘制姿态与站立/飞矛遮挡一致。两侧主题陷阱有看得出启停的危险边界，服务端每次命中约扣最大生命 10%，双方同等受伤；陷阱预警不应被光波遮蔽。本人拳/踢/矛造成 3 次真实伤害充 1 次联机光波（上限储存 1），L 朝当前面向打出约 800×84 的玉白主束，最多对另一位玩家造成固定 20 点伤害，施放者约 18 有效帧短暂受保护；对手闪避/无敌或避开范围则不受伤。光波自己的伤害不充能，绝不复用闯关的全波比例扣血和背后余波命中；低动态下保留短促可辨的束/危险区线索而不震屏。 |
| 渐进地形 | 每章首关从连续楼梯起步，后续逐步出现竖向浮台、后段左右漂移浮台和绕中心微幅旋转的木条；章内 11–14 关位的第二浮台左右幅度递增。视觉位置须与可站立/碰撞、人物承载、飞行物遮挡和 AI 路线所用姿态对应，动态地形在暂停/重试后与固定模拟帧一致。 |
| 单人敌人避险 | 地面陷阱的可见边界及启停状态应与敌人判断的危险区对应；敌人靠近时的起跳、避开或短暂停等能从走位看出，被击退后再次接近不只重复直冲同一区域。实际踩中时保留原机关受击反馈，不用隐形免伤伪装避险；联机玩家对战不套用敌人路线。 |
| 闪避/落地/命中 | 闪避残影、落地扬尘；拳脚命中有高亮、粒子、击退及 4–7 帧打击停顿，地面机关的停顿更短。 |
| 新兵种与里程碑 Boss | 跃袭者保留大头细身但用轻盈长腿/起跳姿态与普通疾行者区分；石掷手以手中小石及后排抛射轮廓提示远程压力，不冒充旧投矛。每十关的 Boss 保持高大剪影，新增投石、召兵、震地、双石与护体须有各自可辨前摇或状态，不与原拳击、偶数关天降小物体、玩家投矛弧线混同。每次召兵最多 2 名、同场活体总上限仍为 5 名，不靠画面粒子数表示；Boss 真实 KO 时其本人召出的活兵同帧各有 KO 番茄与尸体，预设敌或其他来源小兵不因此出现 KO 反馈，也不得被视觉上误示为已清场。小石/警告和场景照片、HUD 之间保持层级。 |
| Boss/光波/坠物 | Boss 更高大且有拳击预警；符合条件的闯关光波从侠客身前聚能并朝面向方向发射主光束，较弱环形余波及各目标命中亮点说明当前波全体受影响，无敌轮廓仍可辨；Boss 受到该招后剩余 HP 为原来的向上取整 2/3，普通敌人为 1/2；偶数关坠物先有可辨预警。 |
| KO 番茄 | 每名被 KO 角色在自己的世界坐标头顶迎来一颗加速下落的烂番茄；约 180ms 撞头且同步湿润砸开声，先压扁回弹再破裂，汁液、果肉向两侧飞溅，头顶污渍短暂保留。双 KO 各自演出；玩家失败与 PvP KO 在正常模式下约 650ms 后出现结果层，此时污渍仍可见。单人末敌 KO 胜利先进入收尾窗口，不把 650ms 结果层盖在可走动舞台上。 |

“灵能武侠”局部增强维持深墨轮廓：只有确认命中的拳脚在接触点短暂显现白芯、暖金/冷青描边与碎墨；投矛命中仍走独立飞行物反馈，不叠近战墨锋。跳踢把玉色弧光收在脚端；光波从侠客身前短暂聚能，朝释放帧的面向方向打出有白芯的玉色主光束，配较弱的环形余波和各敌人命中亮点，保留森林青绿、城市紫灰、海洋青蓝、陆地赭金的微色变化，不作整屏短闪。前向光束不应暗示只伤前方：当前波全部活敌人在发动时结算，含身后目标；Boss 血量改为 `ceil(当前 HP×2/3)`，普通敌人改为 `ceil(当前 HP/2)`。Boss 新招的石块、震地、召兵与护体提示在 10/20/30/40/50 关逐级累加，低动态下仍须能辨其攻击方向和护体状态，不能让强辉光吞没旧拳/坠物预警。摄影背景、侠客面部、投矛预览、坠物/Boss 预警和 HUD 均须保持可读，真实设备目视尚未验收。声音按真实命中、跳踢、投矛、光波与 Boss 起手分层合成；总线压缩并限制 24 个同时声部，关闭音效或切场景时停止尾音，番茄仍与约 180ms 落点同步。具体光束笔画、时序、色值和混音是 D-019/D-021 的本版实现，不改变联机结果；Boss 伤害系数改变属于 D-022 的玩法调整。

上述“前向主束但全波/身后目标也受伤”只描述闯关光波；联机光波的画面长度/高度须与真实前向命中区吻合，只对范围内的另一名玩家结算，不能把闯关的环形余波画到联机对手身上暗示凭空掉血。离屏对手方向提示、旋转木条的落脚表面与主题陷阱边界在光束/番茄演出期间仍应可读。

### 声音层次与播放边界

用户明确要低音量背景音乐，且不得压过击打音效（D-023）。本版用程序合成森林、城市、海洋、陆地四种短循环；音乐始终是氛围底层，打击、跳踢、投矛、光波和 KO 的短促反馈须处在前景。音乐独立于事件音效声部，命中和 KO 时短暂降低音乐再平顺恢复；不通过把打击声整体调大来掩盖音乐，也不让循环音色与命中音色持续争夺注意力。联机两端以房主实际房间主题为准，不随加入者本地下拉残留值改变。单人 `playing`/`aftermath` 与联机 `playing` 才循环；等待、倒数、失败、结算和离开模式时停播。页头“声音”开关同时控制两者，第一次浏览器手势前不自动发声；静音、失焦/隐藏或切局时清尾音，恢复焦点后仅在仍属可播放阶段时续播。无外部音乐素材，也不改生命、碰撞、胜负和存档。以上声部结构与启停时机是本版落实用户体验的选择，**真实设备试听尚未验收**；自动化只能核对门控、混音参数和事件避让，不能证明不同耳机/扬声器上“不会盖住打击”。

系统偏好 `prefers-reduced-motion: reduce` 会把 CSS 动画/过渡压至接近零、取消 Canvas 震屏及部分拳风/坠物/跳踢/投矛的附加尾迹并减少粒子；新增命中墨锋改静态短提示，光波保留短促的前向光束、局部余波与每个目标的确认线索，不作长尾迹或整屏闪光。Boss 新技能与石掷手小石保留简短、方向明确的前摇/飞行/护体线索，减少装饰性尾迹。侠客披风保持静态披垂，不因移动持续摆动，蓑帽与玩家颜色仍可辨；自选头像生效时无默认脸部表情叠绘；减少动态效果也不重新画出眉眼口，KO 番茄、血量和结果文字仍保留。玩家瞄准弧线、预计落点、可见角度、“发射/取消”状态和剩余发数仍应静态可辨。KO 仍有撞击提示、静态头顶污渍及少量（当前 3 滴）汁液，不再播放飞溅弧线/果皮尾迹；玩家失败与 PvP KO 的结果层缩短至约 300ms 出现。单人末敌 KO 仍保留有效帧收尾，不因减少动态而跳过踩骨机会；散骨压缩飞散幅度/粒子数量，但以骨头分离的静态关键帧或短促状态变化保留触发可辨性。默认脸表情、敌人投矛前摇/飞行、闪避残影和关键动作线索仍保留，因此不是“完全静态模式”。当前舞台入场约 0.48s、模式颜色过渡约 0.18s、按钮/节点悬停约 0.16s；新动效应有相应减少动态的处理。

装备掉落徽章与选装状态在减少动态偏好下仍需辨认，但不持续漂浮/闪烁；装备命中保留短促局部确认线索，不增加镜头震动。背包的“已装备”不能只靠色彩表达，拾取、重复拾取和过关自动收纳均有文字反馈。九件装备的具体技能视觉与数值为本版实施选择，跨照片、移动平台、窄屏和真实设备的可读性尚需走查，自动化绘制分支不能替代目视验收。

## 可访问性现状与设计变更检查

当前已有中文页面语言、语义区域、输入标签、Canvas 的 `aria-label` 与不支持 Canvas 时的回退句、状态播报、模式与声音的按下状态、按钮/输入的自定义可见焦点。下拉选择框目前不在该自定义焦点规则内。已通关重打入口、练习状态/退出动作和上传/拍照/清除头像必须有可读名称与键盘焦点，选择失败/权限拒绝应以文字反馈，不能仅靠头像预览或颜色解释；照片不应成为辨认玩家身份/胜负的唯一渠道。**尚未证明** Canvas 战斗可全程读屏、覆盖层有完整焦点管理、所有文本对比度达到某一 WCAG 等级、所有手机相机权限/触控都顺手或光敏安全阈值已测。

做有意的 UI/视觉调整时，建议在变更说明中附：改动前后桌面与 ≤540px 画面、闯关/联机两个模式、正常/减少动态两种设置；逐项核对主操作、HUD 可读性、房间错误与结果状态、当前第 01/27 关照片以及键盘焦点。没有实机或截图就标为未验证，不要用“设计已验收”概括。

联机房间交互的现行基线包括：等待房过期只清理对应房间并关闭旧覆盖层，房主回到可创建/加入状态；P2 加入后主题选择框显示房主主题。两项历史缺陷（PRD G-01/G-02）已有自动回归覆盖，后续调整应维持这些状态语义。若确需重塑品牌或布局，请先和项目所有者确认新方向，再更新本基线、PRD 与相关测试。
