# 视觉与交互设计基线（当前实现）

这是从 [页面](../public/index.html)、[样式](../public/styles.css) 和 [画面绘制](../public/render.js) 归纳的**现行基线**，用于让下一位开发者/AI 延续已有风格；它不是用户签字的品牌规范，也不宣称通过真实设备视觉或无障碍验收。玩法、字段与状态以 [PRD](../outputs/PRD-火柴人竞技场-20261004.md) 为准。

## 体验与视觉层级

- 品牌用“线斗 / STICK ARENA”：倾斜三笔的 CSS 图形、中文主字标和紧凑英文辅助标。不要无缘由换成图片商标或另一套命名。
- 战斗画面优先占据首屏；舞台外是深墨绿框架，右侧路线/房间操作放在浅矿物纸色面板。单人以 960 宽视口窥见 1920 宽的横向关卡世界，镜头跟随人物；联机仍为固定 960 宽画面。当前任务一眼先看对战，再看进度或房间操作。
- 暖橙为主操作、当前关和 P1 提示；珊瑚红区分对手及部分警示，机关仍按各主题使用自己的色彩；四主题绘制场景分别采用森林蓝绿、城市紫灰、海洋青蓝、陆地赭石。场景调色不等于整站切换四套 UI 主题。
- 角色保持“大头、细身、细肢”的火柴人比例；可操控的人类角色（单人主角与联机 P1/P2）以用户提供的侠客图为造型参考：低檐、不规则破边的深色编织蓑帽，暗色面部与状态可辨的亮眼，颈部围巾和流动的披风。P1 以赤红披风为识别点，P2 用对比明显的冷色；这不是对原图的逐像素复制，原图也不作为公开游戏素材。帽檐不能遮没情绪与 KO 番茄落点，披风不能吞没细肢与攻击朝向；画面中的刀只作气质参考，拳、踢、投矛等招式不变。敌人和 Boss 不因此换装。普通头半径约 22 个逻辑像素、肢体核心描边多为 4.2–4.8，Boss 整体视觉约放大 1.28 倍并加宽肩线；服饰只是轮廓/动效，不改变人物命中范围。

|---|---|---|

| 路线/房间面板 | 浅纸色、高对比深字；路线 7 列数字节点，当前/存档/Boss/已通关/锁定有不同标记。练习关另有色框和 `aria-pressed`，右侧出现“退出重打 · 返回主线”。 | 已通关节点可作为临时重打入口，未通关/锁定不可跳关；练习期间主线存档/进度/失败次数仍以“主线”标示，切换另一已通关节点仍只属练习，不把结果冒充正式过关。 |
| 头像设置 | 页头“我的头像”常驻入口（窄屏收起文字但保留按钮），正式准备覆盖层另有“设置头像”；深底对话框含圆形预览、上传、网页相机、权限失败后的系统相机/相册回退、恢复默认和关闭。 | 单人战斗中打开对话框暂停；关闭后按正式/练习分别显示“继续主线”或“继续重打”，再由玩家恢复。联机倒数/正式对战暂禁改，本地失败提示不阻断开战。相机轨道在关闭/失焦时停止，状态文字与键盘焦点须保持可用。 |
| 按钮 | 暖橙主按钮、深色次按钮、描边/安静按钮；禁用有低不透明度；模式选中有底部暖橙强调线。单人投矛显示本关剩余 0–5 发：未瞄准时为“投矛”，瞄准时原位改为“发射”，增显“抬高”“压低”“取消”；触屏调角按钮旁独立显示当前仰角，避免缩小的 Canvas 数字难读；0 发不可瞄准，战斗外/暂停时禁用或隐藏，联机隐藏。 | “发射”是瞄准态的主要行动，“取消”和调角是次级操作；取消还须清除等待处理的第二次 I 输入，不能自动重新瞄准。仰角读数不作为高频实时播报；不得让松开舞台拖动自动发射，也不要把投矛余量误作 KO 充能，光波资格与充能独立判断。 |
| 细节 | 直线、画框角线、斜切笔画、存档菱形为几何语言；地图格仅轻微圆角。 | 不要误读为“全站禁用圆形”：人物头、光波和装饰环本来就是圆形。 |

响应式现状：宽度 ≤1100px 主区上下堆叠；≤760px 页头折行、键盘提示隐藏并显示触控按键；≤540px HUD 隐藏生命数字但保留血条；≤360px 进一步压缩标题与按钮；粗指针设备即使宽度 >760px 也显示触控。页面声明最小宽度 320px，不代表更窄设备经过验收。

## 动作与反馈的视觉语法

| 动作/事件 | 当前表现 |
|---|---|
| 拳击 | 有效帧在拳头附近出现弧形拳风；没有光箭、远程投射物。三段出拳节奏不同。 |
| 连段/胜负表情 | 连续挥拳时努力发力；胜利开心、失败与 KO 伤心。表情叠加在夸张大头上，不能代替血量、KO 番茄和文字结果，也不能在状态变化后残留相反情绪。 |
| 本地自选头像 | 开战前可选本机照片或拍照，文件最多 8 MB、边长≤8192px，缩为 192×192 后裁入本人圆形头部；未选择/清除用默认脸，处理失败保留原有效/默认脸。头部轮廓、亮眼/表情、帽檐、围巾和 KO 番茄保持更高视觉层级；不让照片方框越出头部或盖住判定线索。联机本端只给本人 P1/P2 绘本机照片，对手仍见默认脸；头像不参与生命、命中或跨端同步。 |
| 已通关重打 | 已通关节点是可操作的练习入口，正式当前关仍保持进度高亮，另用绿框标出练习所选关；未通关/锁定节点不得用同一可点击暗示。练习开始层写“开始重打/返回主线”，成功/失败层写“再打这一关/返回主线”，右侧始终可退出，亦可点另一已通关节点换练习关；退出回到原正式现场并暂停待“继续主线”，不把练习胜利写成“进入下一关”或让玩家误以为会覆盖存档。 |
| 蓑帽、围巾与侠客披风 | 单人玩家及联机双方都戴深墨色、低檐破边的编织斗笠式蓑帽；暗色大头上由亮眼和眉眼形状表达开心、伤心、发力，P1 赤红围巾/披风与 P2 冷色围巾/披风在四主题和照片背景上区分人物。披风尾端随水平移动向反方向扬起，起跳/落下时跟随身体姿态变化，减速时逐渐回垂；不盖住拳风、踢击、投矛瞄准弧线、表情和 KO 番茄。减少动态效果时保留静态披垂轮廓，不随速度/时间持续飘动，但仍随朝向/KO 姿态更新。服饰不参与命中、碰撞、伤害或存档。敌人/Boss 保持原造型；不新增刀类武器。 |
| 地面踢/跳踢 | 脚端能量；空中跳踢在有效帧出现碎光、扩散环与短促震屏，空挥仍有完整动作。 |
| 玩家投矛 | 与贴拳拳风明确区分：单人先按 I/“投矛”进入瞄准，舞台显示由当前发射点、朝向和 8°–72° 仰角推算的可读弧线及预计落点；初始角只参考前方最近敌人，无合适目标时为 42°，绝不显示锁敌/必中效果。↑/↓ 或 W/S 和触屏“抬高/压低”可按住连续微调，舞台竖向拖动可调角但松手不发射；左右仍能在瞄准中走位/转向，预览随之更新。再按 I/“发射”确认朝向和角度，20 有效帧蓄势后按固定速度投出；惯性、动态平台及目标移动可使实弹与先前预览的世界落点不同。Esc/“取消”或拳、踢、跳、闪、受击/KO、暂停、失焦、切模式只退出**未确认**瞄准，已确认蓄势不因这些外部切换回退；成功释放有充能的光波会立即打断瞄准或蓄势，空充能/不可用光波不取消瞄准，蓄势还可被受击打断。屏幕显示本关剩余发数；仅实际投出扣 1，瞄准/确认/取消/蓄势被打断不扣；跨波共享 5 发，换关/回档重试恢复，0 发不可重新瞄准。按住 I 不自动连发；联机不出现该按钮、轨迹、飞行物或音效。 |
| 敌人投矛 | 中后期具备资格的敌人沿用自动锁定玩家当时位置的可辨前摇/预告路线，出手后飞行不追踪；敌我双方都可走位、借平台遮挡或闪避。不把玩家手调角流程加到 AI 或联机。 |
| 渐进地形 | 每章首关从连续楼梯起步，后续逐步出现竖向浮台、后段左右漂移浮台和绕中心微幅旋转的木条；章内 11–14 关位的第二浮台左右幅度递增。视觉位置须与可站立/碰撞、人物承载、飞行物遮挡和 AI 路线所用姿态对应，动态地形在暂停/重试后与固定模拟帧一致。 |
| 单人敌人避险 | 地面陷阱的可见边界及启停状态应与敌人判断的危险区对应；敌人靠近时的起跳、避开或短暂停等能从走位看出，被击退后再次接近不只重复直冲同一区域。实际踩中时保留原机关受击反馈，不用隐形免伤伪装避险；联机玩家对战不套用敌人路线。 |
| 闪避/落地/命中 | 闪避残影、落地扬尘；拳脚命中有高亮、粒子、击退及 4–7 帧打击停顿，地面机关的停顿更短。 |
| 新兵种与里程碑 Boss | 跃袭者保留大头细身但用轻盈长腿/起跳姿态与普通疾行者区分；石掷手以手中小石及后排抛射轮廓提示远程压力，不冒充旧投矛。每十关的 Boss 保持高大剪影，新增投石、召兵、震地、双石与护体须有各自可辨前摇或状态，不与原拳击、偶数关天降小物体、玩家投矛弧线混同。召唤兵上限 5，不靠画面粒子数表示；小石/警告和场景照片、HUD 之间保持层级。 |
| Boss/光波/坠物 | Boss 更高大且有拳击预警；符合条件的闯关光波从侠客身前聚能并朝面向方向发射主光束，较弱环形余波及各目标命中亮点说明当前波全体受影响，无敌轮廓仍可辨；Boss 受到该招后剩余 HP 为原来的向上取整 2/3，普通敌人为 1/2；偶数关坠物先有可辨预警。 |
| KO 番茄 | 每名被 KO 角色在自己的世界坐标头顶迎来一颗加速下落的烂番茄；约 180ms 撞头且同步湿润砸开声，先压扁回弹再破裂，汁液、果肉向两侧飞溅，头顶污渍短暂保留。双 KO 各自演出；玩家失败与 PvP KO 在正常模式下约 650ms 后出现结果层，此时污渍仍可见。单人末敌 KO 胜利先进入收尾窗口，不把 650ms 结果层盖在可走动舞台上。 |
| 单人敌人倒地与散骨 | 敌人真实 KO 后有约 27 个有效帧的倒地过程，落稳后在其落点世界坐标留存 180 有效帧（约 3 秒）再自然消失，暂停/hitstop 不计时。活玩家须站在尸体同一实际承载面（地面或同一块平台，含移动/倾斜木条），先离开、再走入尸体范围才触发一次碎骨四散，随即移除尸体；不得在初始重叠时自动散架，也不能仅凭脚底高度相近、隔着浅木板误触。约 0.6 秒碎骨动效是表现，不造成伤害或光波充能；跨波尸体留到自身时限，换关/重试清空。尸体/碎骨与番茄均按世界坐标绘制，镜头移动时不漂移。 |
| 单人末敌 KO 收尾 | 最后一名敌人真实 KO 且玩家仍活着后，舞台继续约 3 秒可左右移动/跳跃、免伤，让单敌第 01 关也能走过倒地敌人；HUD 明示胜利收尾，拳/踢/闪/投矛/光波按钮不可用，先前缓存的拳/踢/闪输入也在进入收尾时清掉，不得在下一有效帧闪现招式。临近窗口结束才散骨时可短暂顺延到动效可见，再出现过关/通关覆盖层。玩家 KO/双 KO 直接失败，没有收尾；胜利表情、番茄与散骨可并存但不遮住人物和关键信息。联机保留原 KO 番茄/胜负，不出现尸体和踩骨。 |
| 照片 | 18 个固定单人关按需加载，准备好后约 250ms 渐入；在宽世界中用同一照片分屏镜像延展，不在镜头移动时换成另一关照片；缺图保留绘制背景，联机永远不用照片。用户明确固定的第 01 关照片、当前放在第 27 关的另一张用户要求保留的照片，都不得在普通改样式时被替换或遮蔽；第 27 关号是现行选位。 |

“灵能武侠”局部增强维持深墨轮廓：只有确认命中的拳脚在接触点短暂显现白芯、暖金/冷青描边与碎墨；投矛命中仍走独立飞行物反馈，不叠近战墨锋。跳踢把玉色弧光收在脚端；光波从侠客身前短暂聚能，朝释放帧的面向方向打出有白芯的玉色主光束，配较弱的环形余波和各敌人命中亮点，保留森林青绿、城市紫灰、海洋青蓝、陆地赭金的微色变化，不作整屏短闪。前向光束不应暗示只伤前方：当前波全部活敌人在发动时结算，含身后目标；Boss 血量改为 `ceil(当前 HP×2/3)`，普通敌人改为 `ceil(当前 HP/2)`。Boss 新招的石块、震地、召兵与护体提示在 10/20/30/40/50 关逐级累加，低动态下仍须能辨其攻击方向和护体状态，不能让强辉光吞没旧拳/坠物预警。摄影背景、侠客面部、投矛预览、坠物/Boss 预警和 HUD 均须保持可读，真实设备目视尚未验收。声音按真实命中、跳踢、投矛、光波与 Boss 起手分层合成；总线压缩并限制 24 个同时声部，关闭音效或切场景时停止尾音，番茄仍与约 180ms 落点同步。具体光束笔画、时序、色值和混音是 D-019/D-021 的本版实现，不改变联机结果；Boss 伤害系数改变属于 D-022 的玩法调整。

### 声音层次与播放边界

用户明确要低音量背景音乐，且不得压过击打音效（D-023）。本版用程序合成森林、城市、海洋、陆地四种短循环；音乐始终是氛围底层，打击、跳踢、投矛、光波和 KO 的短促反馈须处在前景。音乐独立于事件音效声部，命中和 KO 时短暂降低音乐再平顺恢复；不通过把打击声整体调大来掩盖音乐，也不让循环音色与命中音色持续争夺注意力。联机两端以房主实际房间主题为准，不随加入者本地下拉残留值改变。单人 `playing`/`aftermath` 与联机 `playing` 才循环；等待、倒数、失败、结算和离开模式时停播。页头“声音”开关同时控制两者，第一次浏览器手势前不自动发声；静音、失焦/隐藏或切局时清尾音，恢复焦点后仅在仍属可播放阶段时续播。无外部音乐素材，也不改生命、碰撞、胜负和存档。以上声部结构与启停时机是本版落实用户体验的选择，**真实设备试听尚未验收**；自动化只能核对门控、混音参数和事件避让，不能证明不同耳机/扬声器上“不会盖住打击”。

系统偏好 `prefers-reduced-motion: reduce` 会把 CSS 动画/过渡压至接近零、取消 Canvas 震屏及部分拳风/坠物/跳踢/投矛的附加尾迹并减少粒子；新增命中墨锋改静态短提示，光波保留短促的前向光束、局部余波与每个目标的确认线索，不作长尾迹或整屏闪光。Boss 新技能与石掷手小石保留简短、方向明确的前摇/飞行/护体线索，减少装饰性尾迹。侠客披风保持静态披垂，不因移动持续摆动，蓑帽与玩家颜色仍可辨；自选头像也不得遮住默认叠绘的情绪线索。玩家瞄准弧线、预计落点、可见角度、“发射/取消”状态和剩余发数仍应静态可辨。KO 仍有撞击提示、静态头顶污渍及少量（当前 3 滴）汁液，不再播放飞溅弧线/果皮尾迹；玩家失败与 PvP KO 的结果层缩短至约 300ms 出现。单人末敌 KO 仍保留有效帧收尾，不因减少动态而跳过踩骨机会；散骨压缩飞散幅度/粒子数量，但以骨头分离的静态关键帧或短促状态变化保留触发可辨性。表情、敌人投矛前摇/飞行、闪避残影和关键动作线索仍保留，因此不是“完全静态模式”。当前舞台入场约 0.48s、模式颜色过渡约 0.18s、按钮/节点悬停约 0.16s；新动效应有相应减少动态的处理。
